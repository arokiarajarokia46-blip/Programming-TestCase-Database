# Programming Test Case Database

A reusable, language-independent programming test-case dataset.

## Supported Languages
- Python
- C
- C++
- Java

## Dataset Files
- `programming_test_cases.json` — structured test cases for programmatic use.
- `programming_test_cases.csv` — tabular version for viewing and editing.

## Current Problem Categories
- Palindrome
- Factorial
- Prime Number
- String Reversal
- Fibonacci
- Array Sum
- Array Sorting
- GCD

## Purpose
To provide reusable test cases for evaluating program correctness across multiple programming languages.

## Note
This repository stores test data. It does not train an AI model.
